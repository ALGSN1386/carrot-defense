# 🥕 保卫萝卜 · 网页版（顶级验证版）

纯前端、零依赖的塔防小游戏。画面全部由 Canvas 程序化绘制，**仓库内无任何图片资源**。
逻辑层与渲染层彻底分离，**所有玩法数值都可在 Node 里无头仿真与断言**，这是本作"顶级"要求的核心：玩法可自动化验证。

## 运行

```bash
# 方式一：直接双击 index.html（ES Module 需经 http 协议，建议用本地服务器）
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123

# 方式二：任意静态服务器
npx serve .
```

## 验证（无需浏览器）

```bash
npm run verify      # 逻辑断言(18) + 渲染冒烟 + 平衡仿真，全部通过即达标
npm test            # 仅逻辑层断言测试 T-01 ~ T-18
npm run sim         # 仅平衡仿真（验证 PRD §7.3 / R5 难度梯度）
```

### 验证结果（确定性，可复现）

| 策略 | 结果 | 说明 |
|------|------|------|
| 不建塔 `none` | 第 **2** 波失守 ✅ | 失败路径可达 |
| 无脑铺塔 `greedy`（纯瓶子炮、不升级） | 第 **9** 波失守 ✅ | 错误策略被淘汰（9–13 区间） |
| 少而精 `quality`（升级+魔法+太阳花） | **通关**，剩 **11/20** 血 ✅ | 正确策略能赢且不躺赢（10–18 区间） |

- 逻辑断言：**18 / 18 通过**（建造/经济/索敌/护盾/减速/通关判定等）
- 渲染冒烟：5 种塔 + 护盾/减速/灼烧状态在真实对局下零异常

## 架构

```
index.html       页面骨架 + HUD/商店/覆盖层
styles.css       全部界面样式（含移动端响应式）
js/
  config.js      数据层：地图/路径/5 种塔/5 种怪物/15 波 —— 不碰 DOM
  game.js        纯逻辑层：状态机/寻路/战斗/经济 —— 可在 Node 无头运行
  render.js      渲染层：Canvas 程序化绘制 —— 接收真实状态绘制
  ui.js          适配层：DPR 缩放/输入/HUD/主循环 —— 连接逻辑与渲染
sim/
  balance.mjs    平衡仿真：三种策略跑完整对局，验证难度梯度
test/
  logic.test.mjs 逻辑层断言（PRD §9 验收矩阵 T-01~T-18）
  render.smoke.mjs 渲染层冒烟测试（模拟 canvas ctx，零异常校验）
```

## 玩法

- 5 种防御塔：瓶子炮 / 冰冻塔 / 魔法塔 / 太阳花 / 火焰塔，均可升 3 级
- 5 种怪物：小怪 / 快跑怪 / 铁甲怪（护甲）/ 护盾怪（护盾）/ 首领（Boss）
- 15 波，第 5/10/15 波为首领波；怪物生命按波次线性放大
- 操作：点商店卡片或按 `1-5` 选塔 → 点草地建造；点已有塔可升级/拆除；
  `空格` 立即开战、`P` 暂停、`Esc` 取消选择；顶栏可切 1×/2×/3× 倍速

> 设计要点：逻辑层不引用任何浏览器 API，因此 `game.js` 能在 Node 直接 `import` 跑仿真；
> 怪物横向偏移已改为**确定性**（按序分泳道），保证平衡仿真可复现。
