# 保卫萝卜 · 网页版 V2

打开即玩的塔防。5 种防御塔、15 波、单局约 10 分钟。零依赖、零构建、无后端、无账号、无埋点。

## 跑起来

直接用浏览器打开 `index.html` 即可，不需要构建。

或者起一个静态服务器（推荐，ES 模块在 `file://` 下会被浏览器拦截）：

```bash
python -m http.server 8080
# 打开 http://127.0.0.1:8080/
```

## 操作\n\n点一次塔卡只放一座塔——想连放就再点一次卡。暂停时一切按钮都会置灰（包括开波与升级），不会让你点了才吃到「暂停中不能…」的提示。

| 操作 | 方式 |
|---|---|
| 建造 | 点底部塔卡 → 点草地 |
| 升级 / 拆除 | 点场上已有的塔 |
| 开波 | 空格 / 「立即开战」 |
| 选塔 | `1`–`5` |
| 暂停 | `P` |
| 取消选中 | `Esc` / 右键 |

## 这个版本做了什么

上一版的 PRD 产品决策很清楚，但拿到手上没法直接开工——缺地图数据、波次编队、战斗规则、经济公式、状态机、UI 规格。V2 把这六块全部写成了代码：

- **地图是数据**：`js/data.js` 里一张 10×16 的字符网格（`.` 可建造 / `#` 路径 / `o` 装饰），96 个可建造格、27 个路径格、路径长 1656px，都有测试守着。
- **波次是数据**：15 波，每波是「类型 / 数量 / 间隔 / 延迟」的编队表，改难度不碰逻辑。
- **战斗规则写死并被测试覆盖**：最远索敌、护甲减法保底 1 点、护盾先扣、减速取最强不叠加、灼烧每 0.25s 一跳且无视护甲、溅射不衰减、投射物不重新索敌。
- **经济有公式**：起始 320 金币，升级价 `round(造价 × 1.3^等级)`，拆除返还累计投入的 60%，清波奖励 `40 + 波次×10`。
- **状态机显式化**：`build → wave → build…→ won / lost`，暂停是独立开关；结束后建造 / 开波 / 倍速全部锁定，只留重开。
- **倍速不改结果**：3× 不是把 `dt` 放大三倍，而是每帧多跑三步固定步长——放大步长会让碰撞和灼烧 tick 悄悄变味。

## 手感做了什么\n\n这一版的重心从"能跑"挪到了"有反馈"，全部在零素材约束内：\n\n- **受击闪白**：命中瞬间怪物整体闪白（之前这个字段只赋值、从不绘制——等于打中了没反应）\n- **炮口火光**：每次开火在炮口喷一团火，塔身有后坐力\n- **死亡碎裂**：怪物死亡炸成粒子，首领是大一号的爆裂并带震屏\n- **漏怪震屏 + 萝卜发抖**：扣血时画面抖一下、萝卜歪头，血量低于 45% 表情变成哭脸\n- **独立剪影**：小怪带角、快跑怪细长带速度线、铁甲怪八角带铆钉、护盾怪带六边能量罩（随护盾值变淡）、首领带犄角和王冠\n- **下一波预告**：布防阶段直接告诉你下一波来什么、有没有首领\n- **程序化音效**：7 种音效全部用 WebAudio 振荡器现场合成，仓库里 **0 个音频文件**，可静音\n\n## 难度不是"感觉"，是仿真跑出来的

`scripts/sim.js` 在 Node 里以固定步长把整局跑完，不需要浏览器。三种打法必须落在固定区间：

```
不建塔        失守  第 2 波        剩余生命 0/20
无脑铺塔      失守  第 13 波       剩余生命 0/20
少而精        通关  第 15 波       剩余生命 14/20
```

任一数值改动后重跑 `node scripts/sim.js`，断言不通过就是回归。

## 测试

```bash
npm test          # 44 个用例：node --test tests/rules.test.js tests/state.test.js
npm run sim       # 无头难度断言（三种打法必须落在固定区间）
npm run e2e       # 浏览器端到端（需要先起浏览器，见下）
```

单测覆盖：地图不变量、波次数据完整性、护甲/护盾/减速/灼烧结算、索敌、经济公式、拆除返还、状态机准入（含暂停）、敌人移动与终点夹取、同时漏怪不出现负血、倍速与确定性。

端到端是真实点击 canvas 的，需要两步：

```bash
python -m http.server 8080
msedge --headless=new --remote-debugging-port=9222 about:blank
node scripts/e2e.js --url http://127.0.0.1:8080/ --port 9222
```

它会禁用浏览器缓存后重新加载页面，所以改完源码直接跑就是测新版。

## 结构

```
index.html
styles.css
js/data.js      地图 / 塔 / 怪物 / 波次 / 经济 —— 唯一允许改数值的地方
js/rules.js     战斗规则（纯函数，无状态）
js/game.js      状态机 + 帧推进（不碰 DOM / Canvas）
js/render.js    全部画面程序化绘制，仓库里没有一张图片
js/ui.js        DOM、输入、主循环
scripts/sim.js  无头平衡仿真
tests/          单元测试
```

`js/game.js` 与 `js/rules.js` 不引用任何浏览器 API，这正是它能在 Node 里跑仿真的原因。

## 已知限制

- 只有一张地图；难度曲线是为这张图调的。
- 没有存档、没有排行榜、没有关卡选择——都不是遗漏，是范围内的取舍。\n- 只有一条音效轨，没有背景音乐。
- canvas 内容对读屏软件不可达，键盘操作可用；切换类按钮带 `aria-pressed`。
- 平衡靠仿真校准，仿真替不了真人手感；真机体验仍需人来判断。
- **主线程卡顿会造成游戏时间损失**：卡 1 秒只推进约 0.4 秒。这是刻意的取舍——宁可让游戏变慢，也不让敌人在卡顿后瞬移穿过防线。代价是长时间卡顿后游戏会永久落后于真实时间。
- **一座一级塔打不穿第 1 波**是设计意图，不是 bug：不建塔会在第 2 波失守，一座塔勉强能拖住第 1 波但清不掉。
